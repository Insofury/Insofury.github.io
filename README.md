# Ashish Chahar · Portfolio

Personal portfolio of **Ashish Chahar**, Senior Software Engineer at HCLTech and Jama Connect SME.

Live site: https://insofury.github.io/

Built as a static site (HTML, CSS and vanilla JavaScript) and hosted on GitHub Pages.

## Files

- `index.html`: page content
- `styles.css`: styles (dark and light themes, responsive layout)
- `script.js`: theme toggle, mobile menu, scroll effects
- `Ashish_Chahar_Resume.pdf`: downloadable resume
- `favicon.svg`: site icon
- `projects/`: screenshots for the featured project cards (ResumeRadar, Reelora and PixelPal)

To update the site, edit these files on GitHub (or upload new versions); GitHub Pages republishes automatically.
