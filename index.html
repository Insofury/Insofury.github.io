ResumeRadar: resume vs job description matcher

Upload a resume and paste a job post to get a 0–100 match score, the must-have skills you're missing, keyword gaps, experience and degree checks, and 15 ATS-style resume checks. Personal project · Open source

PixelPal: bulk image toolkit

Remove backgrounds with AI, resize, compress (even to a target file size), convert between PNG, JPG and WebP, and add watermarks to up to 50 images at once, then download them as a ZIP. It's built in Python with Pillow, rembg (U²-Net) and FastAPI. The live demo runs the same Python code in the browser with Pyodide and runs the AI model on the visitor's GPU with onnxruntime-web, so images never leave their device.
